# 후속 결정 및 검토 제안

이 문서는 최초 decisions.md의 미정 목록보다 우선하는 후속 기록이다. 제안 항목은 사용자 승인 전 확정하지 않는다.

## 최신 답변 반영 — 앞선 기록보다 우선

### 보관·스택·Compose 확정 — 최신 답변 우선

검증 결과: Compose 설정 검사, DB healthy 및 실제 SQL 접속(PostgreSQL 18.6), Node 도구 실행(v26.13.0), 컨테이너 파일 생성 후 호스트 `file/` 확인·probe 제거를 통과했다. 공식 OpenSpec CLI strict 검증도 통과했다. 최초 검증의 spec 내 계획 메모 경고는 내용을 design.md로 이동하여 해소했다. 제품 웹·워커 실행 검증은 아직 해당하지 않는다.

- 오류·검토 대기 중 최초 원본을 유지하고 정상 최종 응답 완료 후 삭제한다.
- 정상 결과·다운로드 파일을 계속 보관하며 스냅샷 삭제 후에도 버전·위치·인용 등 근거 패널 정보를 유지한다.
- 설정 가능한 보관 루트, 기본은 프로젝트 루트 `file/`.
- 최신 안정 호환 버전의 SvelteKit/shadcn-svelte/Tailwind CSS/PostgreSQL 및 별도 로컬 워커를 확정했다.
- 사용자가 컨테이너 선호, Docker Compose 필수 설정 및 기본 실행, 향후 Linux 전환을 요청했다. 이에 Compose 실행 기반 구현은 승인된 범위로 처리한다.
- 실제 Linux Docker 엔진 접근 및 공식 이미지 pull로 PostgreSQL 18.6과 Node LTS 26.13.0을 확인하고 digest로 고정했다. 웹 라이브러리 버전은 아직 설치·확정하지 않았다.
- compose.yaml, 일회성 tools 서비스, DB secret 파일 생성 안내, 기본 file 폴더 및 Git 제외 설정을 추가했다. 제품 웹·워커·CLI 로그인 연결은 아직 미구현이다.

### 구현 전 정책 답변 — 최신

- 원본을 유지하고 복사본을 가공하며 다운로드 결과물 생성을 포함한다. 외부 전송은 확인받는다.
- 표현 차이만 있고 핵심 사실·수치·대상·근거가 같으면 일치다. 수치 불일치/검산 실패는 정리 중단 및 불일치 표시다.
- 태스크 대기열을 채택하고 추후 동시 실행으로 전환 가능하게 구성한다.
- 정상 응답 후 원본 스냅샷 삭제. 오류/검토 결과는 DB 및 별도 로컬 파일로 보관하고 경로를 DB에 기록한다. 오류/검토 원본, 정상 결과물 보관 기간, 삭제 후 근거 표시 범위는 미정이다.
- 관리자 초대. 발신/수신 변경 및 메일/푸시 개별 선택 허용. 반응형 웹으로 개발한다.
- 사용자 제안은 SvelteKit + shadcn + Tailwind CSS + PostgreSQL 최신 버전. Svelte용 shadcn-svelte 및 최신 안정 호환 버전 고정을 추천했으며 아직 설치하거나 버전을 확정하지 않았다.
- 사용량/네트워크/500/내부 실행 및 기타 실행 오류는 모두 즉시 알리고 중단한다. 자동 재시도하지 않는다.
- 500을 무조건 앱 내부 오류로 간주하지 않고 실제 오류 단계·종류를 구분해 기록한다.
- 정식 안정버전 정책, 오류/검토 원본 유지, 정상 결과물 보관 및 로컬 저장 경로를 추가 확인한다.

### 최종 후속 답변 — 이 블록 우선

#### 범용 예약 정정 — 이후 답변으로 확정

- 예약 업무 및 일정은 사용자의 요청으로 정한다. 연구 과제 분석 및 월–목 10시/14시는 한 가지 예시이며 제품의 고정 동작이 아니다. 공휴일 규칙을 임의 적용하지 않는다.
- 요청한 예약 시각은 해당 태스크 실행 시작 시각이다.
- 소유자 PC가 꺼져 생긴 누락은 복구 후 작업별로 한 번 실행한다. 같은 작업의 여러 누락을 개별 반복 재생하지 않는다.
- 불일치 재검토는 최초 실행의 원본 버전을 그대로 사용한다. 다음 정기 실행에서 최신 파일을 읽는 정책과 구분한다.
- 사용자에게 실제 분석 파일의 버전과 확보 시각을 표시한다. Drive 리비전과 로컬 스냅샷 식별자는 구분한다.
- scheduled-tasks spec을 추가하고 기존 연구 보고서 spec을 조건부 예시로 정정했다.

- 초대한 사용자만 이용하며, 소유자의 Claude Pro/ChatGPT Plus 사용량 공유는 의도한 동작이다. 향후 LLM API 전환은 현재 범위 밖이다.
- 사용자가 앱에 허용한 파일만 검색한다. 전체 Drive 읽기 권한 제안은 채택되지 않았다.
- 복수 파일 후보는 선택받고, 예약은 최초 선택 파일을 유지하며 매 실행 최신 내용을 반영한다.
- 사용자별 성공 완료마다 대조·정리 담당을 함께 교대한다. 최초 Claude, 다음 Codex다. 실패는 순번을 전진시키지 않는다.
- 당일 숨김은 해당 작업의 정상 메일·푸시에 적용하며 분석은 계속한다. 오류는 통지하고 한국시간 자정에 해제한다.
- 관련 delta specs 및 기술 중립 design.md 초안을 갱신했다. 구현/예약 생성/메일 발송은 하지 않았다.

- ngrok을 유지하되 터널에서 소유자 이메일로 제한하지 않는다. Google OIDC 로그인과 사용자별 Drive OAuth/API 연동으로 전환한다. 본인 전용이라는 초기 가정은 더 이상 설계 전제로 사용하지 않는다. 실제 가입·실행 허용 범위는 확인한다.
- 날짜는 시작일 포함 30일: 11/1–11/30, 11/2–12/1. 과거의 달력상 한 달 제안은 채택되지 않았다.
- 파일 링크를 필수로 받지 않고 자연어로 파일을 검색한다. 중복 후보 처리와 예약 시 재검색 여부는 미정이다.
- 알림은 메일과 브라우저 푸시로 제한한다. 0건도 알리고 "오늘은 알림 더 표시 안함"을 제공한다. 적용 단위·채널·오류 예외는 미정이다.
- 최종 정리 담당은 영속 상태 기반 라운드로빈이다. 대조 담당도 함께 순환하는지, 전역/사용자/작업 단위인지, 실패 시 전진하는지는 미정이다.
- 근거 패널, 동일 원본 버전, 코드 검산은 채택되었다. 재검토 때 원본 갱신 여부는 미정이다.
- Google OAuth를 통한 Drive API 접근은 허용되었다. scopes는 아직 선택하지 않았다.
- Open Design 실행 앱이 확인되지 않아 사용자 지시에 따라 UI/UX Pro Max로 전환했다. 스킬 파일 및 로컬 검색 스크립트를 확인했고 외부 생성 서비스를 호출하지 않았다. 구체적 색상·서체·스타일은 확정하지 않았다.
- DB 엔진 및 보관 정책은 추후 논의한다. 라운드로빈 상태 등의 영속 보관 요구만 기록한다.

### 기술 확인

- OIDC 로그인은 사용자 식별이며 Drive 읽기는 별도 OAuth scope와 access token이 필요하다.
- `drive.readonly`는 전체 접근 가능한 Drive 파일의 읽기/다운로드 권한이며 restricted scope다. Google 공개 앱 검증·심사 범위는 배포와 데이터 처리 방식에 따라 확인해야 한다.
- `drive.file`는 사용자가 앱에 선택/공유한 파일 중심으로 접근하므로 미선택 파일 전체의 자연어 검색을 대신하지 못한다.
- 로그인 사용자가 접근할 수 있는 공유 파일도 권한 내 검색 대상이 될 수 있다. 파일 소유자와 로그인 사용자가 반드시 같은 것은 아니다.
- 앱의 사용자별 작업·결과·캐시·알림 격리는 Google 로그인만으로 자동 구현되지 않는다.

참고: https://developers.google.com/identity/openid-connect/openid-connect 및 https://developers.google.com/workspace/drive/api/guides/api-specific-auth

아래는 이전 답변 시점의 기록이며 최신 결정과 충돌하는 항목은 더 이상 미정/제안으로 취급하지 않는다.

## 확인된 결정

- 사용자: 본인만 사용. 외부 접속 필요. ngrok을 우선 계획하며 대안도 비교 요청.
- 첫 업무: Drive의 교내 연구 과제 Excel, 월–목 평일 10시/14시, 한 달 내 마감 항목, 원본 헤더와 행 형태의 표 전달.
- 실행: 두 도구에 별도 프롬프트 전달 → 각 1회 실행 → 한쪽 LLM이 대조 및 정리.
- 첫 불일치: 사용자에게 표시. 사용자 요청 시 불일치 사실만 피드백으로 추가하여 각각 재수행.
- 두 번째 불일치: 에러 메일 및 알림.
- 사용량/API/네트워크 오류: 즉시 사용자에게 전달.
- 파싱: 스캔 PDF·이미지 OCR, Excel 수식·차트 해석 포함.
- 구독: Claude Pro 및 ChatGPT Plus.
- 보관: PC 보관 가능. DB와 보관 기간은 추후 논의.

## 제안 — 미승인

- 외부 접속: ngrok + 본인 계정만 허용하는 인증, Tailscale Serve, Cloudflare Tunnel + Access 비교. 무료 범위는 최종 선택 시 재확인.
- 근거 UI: 원본 표를 유지하고, 행을 선택하면 별도 패널에 파일명·시트·셀 범위·조회 시각·원본 발췌·Drive 열기를 표시. PDF는 페이지 및 강조 영역, 슬라이드는 장 번호 및 미리보기, 이미지는 인식 영역을 표시.
- 결과 대조 전 두 도구가 같은 파일 버전을 참조하도록 원본을 보존. 재검토 시 버전 재사용 여부는 사용자 확인 필요.
- 날짜 필터와 수치 검산을 일반 코드로도 검증하는 방안. 두 모델의 합의 자체를 원본 검증 완료로 취급하지 않음.
- Drive 연동은 현재 채팅의 플러그인, 각 CLI에서의 플러그인/MCP, 독립 앱의 Google OAuth/Drive API, Drive 동기화 폴더를 구분하여 검증. LLM API 금지와 Google Drive API 사용 여부는 별도 결정.

## Open Design 재확인

- 캐시의 Open Design 0.5.2 플러그인 패키지, README 및 스킬 파일을 확인했다. 이것만으로 활성 런타임 설치를 증명하지 않는다.
- 패키지 README는 플러그인에 MCP 서버가 포함되지 않으며 별도 Open Design 앱의 로컬 MCP 등록을 재사용한다고 명시한다.
- 현재 도구 목록에 Open Design 실행 도구가 없으며 `codex mcp get open-design --json`은 등록 없음으로 반환했다.
- Windows 일반 설치 위치, 제거 프로그램 레지스트리, 시작 메뉴, 실행 프로세스 및 PATH에서 런타임 위치를 찾지 못했다. 사용자 지정/포터블 설치 가능성은 남아 있다.
- 별도 CLI의 plugin list는 원격 플러그인 카탈로그 조회가 네트워크 오류로 실패하여, 데스크톱의 전체 플러그인 활성 상태를 증명하는 데 사용할 수 없다.
- 설치 및 MCP 설정 변경은 하지 않았다. 앱 실행 파일 경로 확인 후 연결 복구 가능 여부를 판단한다.
